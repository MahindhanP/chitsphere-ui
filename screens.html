Every screen in ChitSphere, and what it does

The prototype now follows the API contracts, documentation and code in the saas-platform repository. Each card below shows the real prototype page, explains it in plain words, and names the calls it stands for. Field names, statuses and error codes come from the contracts.

  • Two portals, one sign-in. ChitSphere staff use the Platform Console; staff of a chit company use their organisation’s workspace. Accounting pages serve both: ?realm=platform opens ChitSphere’s own books.
  • Modules follow the plan. Chits, Customers, HRMS, CRM, Payroll and Accounting appear in the menu only as the plan allows; others show “Not in plan”.
  • Screens with no API were removed: self-registration, the member app and its store builds, invoices, KYC review and MRR.
  • Use the switches to see every screen in each organisation theme, light or dark. Hover a screen and click to try it in place; the chips under each note switch to its other states.
